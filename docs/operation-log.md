## 2026-09-18

### 接口与链路交互优化

- 去掉点击接口名称直接打开编辑弹窗的行为，接口名称改为纯展示。
- 接口右侧按钮统一为“编辑接口”（`EditPen`）和“创建连接”（`Plus`）。
- 链路弹窗改为节点与链路卡片组合布局。
- 链路卡片显示连接名称、线缆类型、线路颜色和业务备注，并提供编辑连接入口。

### 接口弹窗优化

- 调整编辑接口弹窗底部操作区布局。
- 删除接口固定在左侧，取消和保存固定在右侧。
- 三个按钮统一高度、最小宽度和间距，避免删除按钮与取消按钮挤在一起。

### 侧栏滚动优化

- 将工作区高度固定为浏览器视口减去顶部栏高度，避免左右栏内容把页面无限撑高。
- 左侧导航栏和右侧详情栏改为独立纵向滚动容器。
- 中间画布区域保持在工作区内，不随侧栏内容长度向下拉长。

### 设备弹窗优化

- 修复编辑设备弹窗中备注文本域只占半宽的问题。
- 为备注 tabs、tab 内容和 textarea 显式设置 `width: 100%`，确保备注输入区域填满弹窗内容宽度。

### 画布交互优化

- 禁止机房画布、设备画布和机柜正反面区域内的文字被选中复制。
- 保留侧栏、详情栏、弹窗和备注预览区域的正常文本选择能力。
- 调整设备视图外部接口锚点排列：按外部连接数量自动分列，行内等距排列，超过一行向上新增出口行。
- 外部锚点排序只计算当前设备当前面可见的外部连接，不再受设备内部连线影响，也不再按 5 个位置循环重叠。
- 统一外部接口标签显示规则：不再混用连接名称，固定显示为 `机柜 · 设备 · 接口` 的对端接口路径。
- 外部接口标签默认隐藏，仅在悬浮对应连接时显示，避免多条外部连接文字挤在上方出口区。
- 将设备标题栏整体上移，并同步调整标题文字位置，为外部连接标签保留独立的上方显示空间；接口网格坐标保持不变。

### 连线交互修复

- 缩小设备连接线箭头，并取消箭头随线宽放大的默认行为。
- 将连接编辑点击事件绑定到整组连线，避免点到可见线条或锚点时不弹出编辑窗口。
- 略微加宽透明点击区域，提高细线命中率。
- 修复箭头过小导致不可见的问题，改为更小但稳定可见的 SVG marker。
- 删除连接确认成功后自动关闭编辑弹窗并清理编辑状态。
- 将连接箭头从 SVG marker 改为实际 polygon，箭头跟随线缆颜色显示，并在悬浮时和连线一起变为不透明。

### 连接弹窗优化

- 调整编辑连接弹窗底部操作区布局。
- 删除连接固定在左侧，取消和保存操作固定在右侧。
- 直接约束连接弹窗的 `el-dialog__footer`，避免插槽渲染结构变化导致布局失效。
- 取消、保存和删除按钮统一高度，并分别设置稳定的最小宽度。

### 交互修复

- 修复机房画布中点击机柜会误提示“机柜位置已保存”的问题。
- 机柜只有实际拖动并导致坐标变化时才会调用位置保存接口。

### 工程化拆分

- 将页面级类型集中到 `frontend/src/domain.ts`。
- 将画布尺寸、设备网格和连线配置集中到 `frontend/src/constants.ts`。
- 将 Markdown 渲染、接口坐标和连线路径计算分别抽离为独立模块。
- 将 API / 数据库健康检查抽离为 `useServiceHealth` composable。
- 将顶部栏和视图工具栏接入 `AppTopbar`、`ViewToolbar` 组件，页面保留业务状态和事件处理。
- 移除旧模板及未使用的连接端点辅助函数，修复导入菜单重复触发文件选择器的问题。
- 为模块边界和组件职责增加简洁注释，便于后续维护。
